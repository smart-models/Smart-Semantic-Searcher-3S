# Contributor Agreement signatures

Each line below is a signature of the
[Smart Semantic Searcher (3S) Contributor Agreement](CONTRIBUTOR-AGREEMENT.md).

How to add yours:

- Add it in your first pull request, in a commit whose author email GitHub
  links to your account, signed off with your name (`git commit -s`). The pull
  request must be opened from that same account.
- Keep the rows in alphabetical order of GitHub account, so that two open pull
  requests rarely touch the same line. If the file conflicts anyway, rebase on
  `main` and keep both lines.
- Fill in "Contributing for" only if you contribute on behalf of an employer.
  If you are under eighteen, your parent or guardian adds a line too.
- Forgot it? Add it in a new signed-off commit to the same pull request; it
  covers the earlier commits. If your first pull request is closed without
  being merged, add the line again in your next one.
- Never edit someone else's line.

For the maintainer: merge a contributor's first pull request without
squashing, so that the signature commit stays in the history, and check that
the pull request author is the account that signed.
